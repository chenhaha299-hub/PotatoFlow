# PotatoFlow 三层级备忘录 + 整篇生成网图 重构报告

**日期**: 2026-08-06（第五轮，大重构）

---

## 用户需求

> "生成独立网图生成的是蓝色框里大标题里所有的内容生成一个独立网图，不是其中一个想法生成"
> "我的网图是有三个层级的，那这个备忘录也要同步三个层级，这样生成网图的话，可以和网图里的三个层级对上"
> "生成网图的入口放在中间顶部"

---

## 重构内容

### 1. 备忘录支持三层级（原只有一级平铺）
- 详情面板新增**"为这个想法建立子层级"**按钮（memo 版 createOrOpenMemoChild）
- 选中想法 → 建二级备忘录页（memo-sub，workspace=memo，level=2）→ 自动进入
- 二级页想法可再建三级
- level 2/3 页面：顶部显示"第 N 层 · 标题" + **"← 返回上级"**按钮；左侧目录隐藏（子层级不需要备忘录列表）
- 想法节点新增 `memoChildPageId` 字段指向子页

### 2. 生成独立网图 = 整篇备忘录（重写 createOrOpenMemoGraph）
- **入口放中间顶部**（"生成独立网图"按钮，与"修改标题/添加想法"同排）
- 递归遍历备忘录层级树 → 生成网图层级树：
  - 备忘录一级页所有想法 → 网图一级页节点（每个想法=一个圆点）
  - 有 memoChildPageId 的想法 → 递归生成网图二级页（含其所有子想法）
  - 二级 → 三级同理
- 一个备忘录只生成一张网图（`memoGraphPageId` 标记，再点变"进入对应网图"）
- 附件（图片/文件）深拷贝到对应网图节点

### 3. 节点布局修复（过程中发现的真 Bug）
- **整篇生成时多个节点坐标挤在一起（28px 偏移 < 节点直径）→ 严重重叠，用户点不到下面的节点**
- 修复：**黄金角螺旋排布**（半径随数量增大），节点分散不重叠

### 4. 详情面板生成按钮同步改整篇入口
- 原"生成独立网图"（单节点）改为"生成整篇网图"（文案同步）

## E2E 新坑（回填 qa-tester 素材）

1. **SVG 节点重叠时 mouse.click / locator.click 都点不准**（命中测试返回最上层节点）→ 先确认节点布局不重叠
2. **`svg g[class*=logicNode]` 会匹配 childCount 徽标 g** → 用 `:has(circle[class*=logicNodeHitbox])` 排除
3. **整篇生成节点布局**：多个节点必须分散排布（螺旋），否则用户点不到
4. **label 截断**：生成后网图节点 label 是 6 字截断，断言要用截断后文本
5. **网图卡片定位**：`[class*='logicPageCard']`（CSS module 哈希类名），不能直接 .logicPageCard
