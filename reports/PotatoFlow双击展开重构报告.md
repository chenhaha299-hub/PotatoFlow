# PotatoFlow 备忘录双击展开子层级 重构报告

**日期**: 2026-08-06（第六轮）

---

## 用户需求

> "备忘录不要做成这样，直接双击想法栏进入下一页，页面设置同样和图1界面一样，只是展开了"
> "双击图2的输入框，会进入到由输入框拓展进去的子备忘录，界面保持一致，但是颜色要产生区别避免混淆"

**确认的三点**：
1. 左侧目录显示**当前想法的子条目**（由子条目进行的拓展）
2. 颜色由我定
3. 去掉"为这个想法建立子层级"按钮，**双击进入就够了**

---

## 改动内容

### 1. 双击进入子备忘录（替代按钮）
- 中间想法条目加 `onDoubleClick` → 直接进入该想法的子备忘录
- 没有子页 → 自动创建并进入；已有子页 → 直接进入
- `createOrOpenMemoChild` 增强：接受 node 参数（避免双击时 selectedNode state 异步未更新的问题）
- **去掉**详情面板的"为这个想法建立子层级"按钮

### 2. 子备忘录界面 = 一级界面完全一致（三栏）
- 布局完全一致：左侧目录栏 + 中间想法列表 + 右侧详情面板
- 顶部：修改标题 / 生成独立网图(仅一级) / 添加想法
- **左侧目录**：一级=备忘录目录；二级/三级=**当前想法的子条目**（子备忘录列表）
- 顶部右侧：一级="＋ 新建备忘录"；子层级="← 返回上级"
- 标题显示层级：一级="备忘录"；二级="第 2 层 · 标题"；三级="第 3 层 · 标题"

### 3. 颜色区分层级（避免混淆）
| 层级 | 主题色 | 效果 |
|---|---|---|
| 一级 | 绿色系 | 现状（默认） |
| 二级 | **橙色系** | 目录浅橙背景、标题橙色、选中态橙边 |
| 三级 | **紫色系** | 目录浅紫背景、标题紫色、选中态紫边 |
