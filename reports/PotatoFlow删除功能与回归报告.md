# PotatoFlow 备忘录/网图删除功能 + 完整回归报告

**日期**: 2026-08-06（第四轮）
**背景**: 用户反馈"备忘录目录的项目删不掉"、"逻辑网图的灵感收集也删不掉，这个不是固定功能，要可以删除"

---

## 一、根因分析（两个 bug）

### Bug 1：备忘录目录根本没有删除入口
- 网图目录卡片有"删除"按钮，但**备忘录目录条目上没有**（功能只服务网图模式）
- 修复：备忘录目录条目加"×"删除按钮（hover 显示，aria-label=`删除备忘录{标题}`）

### Bug 2：删除后自动重建（"删不掉"的真凶）
- useEffect（源码 325-369 行）检查：**只要没有 graph/memo 一级页就自动补建一个"灵感收集"**
- 删掉"灵感收集"→ effect 立即重建 → 看起来永远删不掉
- 修复：**移除自动补建逻辑**——用户删光就删光，不强制保留默认页

### Bug 3（顺带发现）：备忘录编辑页没有删除确认弹窗
- 删除确认弹窗只在 `!activePage` 的目录分支渲染
- **备忘录编辑页（有 activePage 时）点了删除按钮，没有弹窗** → 看起来"点了没反应"
- 修复：备忘录编辑页补上删除确认弹窗（输入"确认"→永久删除）

### Bug 4（顺带修复）：删除当前打开页后 activePageId 悬空
- 删除正在查看的页后 activePage 变 null，界面可能空白
- 修复：删除后自动打开第一个剩余页（或回到目录）

---

## 二、删除功能行为（已实现）

- **备忘录目录**：条目 hover 显示"×"，点击 → 确认弹窗（输入"确认"）→ 永久删除
- **逻辑网图目录**：卡片"删除"按钮 → 确认弹窗 → 永久删除
- **删除范围**：该页的全部想法、图片、文件、二三级子网图（级联）
- **不自动重建**：删光后不强制补建"灵感收集"
- **删除当前页**：自动切换到剩余第一页
- 备忘录删除文案："这篇备忘录的全部想法、图片和文件都无法恢复"
- 网图删除文案："这张网图的圆点、连线、源文件关联以及全部二、三级子网图都无法恢复"
