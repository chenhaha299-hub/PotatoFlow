## 一、项目是什么

PotatoFlow = 个人执行系统（个人知识管理 + 思维可视化工具），技术栈：

- **Monorepo**：pnpm workspace（vinext + React 19）
- **Web 端**：`apps/web`，数据存 localStorage（key: `potatoflow:v1`），有云同步（乐观锁整包覆盖）
- 主组件：`apps/web/app/LogicGraphPrototype.tsx`（核心，约 2100 行）
- 样式：`apps/web/app/potatoflow.module.css`
- 导航/布局：`apps/web/app/PotatoFlowApp.tsx`

## 二、如何启动（开发）

```bash
cd apps/web
npm install          # 安装依赖
npm run dev          # 开发模式（默认 3001）
```

**生产模式（本机验证用）：**
```bash
npm run build        # 构建（vinext）
npm run start -- --hostname 0.0.0.0 --port 3001   # 起服务
```

**注意**：
- 改源码后必须 `npm run build` 再重启服务（`npm run start` 跑的是 dist 旧构建）
- 浏览器看新版要 **Ctrl+F5** 强刷（有 service worker 缓存旧版）
- 杀进程：`netstat -ano | grep ":3001" | grep LISTENING` 取真实 PID 再 terminate（npm wrapper 杀了没用）

## 三、两大模块

### 1. 备忘录（模式 memo）
- 左侧导航"备忘录"进入；左侧目录列备忘录，中间想法列表，右侧详情面板
- **添加想法**：点"＋ 添加想法"→ 内联输入框（非弹窗），回车提交
- **层级**：**双击想法条目**进入子备忘录（二级），再双击进三级；界面三栏一致
- **颜色区分层级**：一级绿 / 二级橙 / 三级紫
- 返回上级按钮在中间编辑区顶部（"修改标题/添加想法"那一排最左边）
- 删除：目录条目右侧"×"（始终可见），确认需输入"确认"

### 2. 思维网图（模式 graph，原"逻辑网图"）
- 左侧导航"思维网图"进入；网图目录卡片，01/02 编号
- 画布 SVG 圆点 = 想法节点；可拖拽、缩放、连接
- **三级结构**：选中节点 →"为这个点建立子网图"→ 二级页 → 三级页
- 节点状态四色：红=已完成、橙=完成中、绿=未完成、黑=默认

### 3. 备忘录 → 思维网图（核心联动）
- 备忘录中间顶部"**生成独立网图**"（一级才有）
- **整篇备忘录**生成一张思维网图（不是单个想法）
- **层级树完整对应**：备忘录一级想法→网图一级圆点；有子层级的想法→网图二级页（递归到三级）
- 一个备忘录只生成一张，再点变"进入对应网图"
- 图片/文件附件深拷贝到网图节点；生成后两边独立（改备忘录不影响网图）

```bash
node e2e/acceptance-final.mjs        # 终验 6 项
```

- 合计 **27/27 通过**（2026-08-06 最后一轮）
- 测试用独立 browser context（隔离 localStorage），数据统一"验收测试"前缀，不碰真实数据
- fixtures/test-note.txt 是测试附件

### E2E 已知坑（重要）
1. **SVG 节点点击**：transform 坐标下 mouse.click/locator.click 会错位 → 节点必须分散布局（螺旋排布），点击用 `:has(circle[class*=logicNodeHitbox])` 定位
2. **label 截断**：想法 label 自动截断 6 字，断言用截断后文本
3. **CSS Module 哈希类名**：`.logicPageCard` 匹配不到，用 `[class*='logicPageCard']`
4. **overlay 拦截**：`_logicOverlay` 遮罩可能拦截点击，导航后需 dismiss
5. **hidden input**：文件上传用 `setInputFiles` 直接注入
